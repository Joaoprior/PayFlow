# 💳 PayFlow — Sistema de Gestão de Cobranças

O **PayFlow** é uma aplicação web desenvolvida para facilitar o gerenciamento de clientes, cobranças e pagamentos, oferecendo uma interface intuitiva e organizada para acompanhar operações financeiras.

O projeto tem como objetivo centralizar informações, simplificar o controle de cobranças e proporcionar maior praticidade na administração financeira.

##  Funcionalidades

###  Dashboard

Painel inicial que apresenta uma visão geral do sistema, permitindo acompanhar as informações financeiras e acessar rapidamente as principais funcionalidades.

###  Gestão de Clientes

Área destinada ao gerenciamento dos clientes cadastrados no sistema, facilitando a organização e a consulta de informações.

###  Gestão de Cobranças

Permite administrar as cobranças registradas, acompanhar seus respectivos valores e consultar informações relacionadas aos pagamentos.

###  Consulta de Boletos

Funcionalidade destinada à consulta dos boletos cadastrados, facilitando a localização e o acompanhamento das cobranças.

###  Processamento de Alterações

Área responsável por processar alterações relacionadas aos registros e às informações do sistema.

###  Controle de Pagamentos

Permite marcar cobranças como pagas, facilitando o acompanhamento da situação financeira e a identificação de pagamentos pendentes.

##  Tecnologias utilizadas

- **PHP** — Desenvolvimento da lógica do sistema e processamento no servidor.
- **MySQL** — Banco de dados para armazenamento das informações.
- **HTML5** — Estruturação das páginas.
- **CSS3** — Estilização e identidade visual.
- **JavaScript** — Interatividade e funcionalidades da interface.
- **XAMPP** — Ambiente de desenvolvimento local com Apache e MySQL.
- **Git e GitHub** — Versionamento e gerenciamento do código-fonte.

## Interface

O PayFlow possui uma interface com tema escuro, elementos visuais modernos e navegação organizada, buscando proporcionar uma experiência simples e intuitiva.

##  Como executar o projeto

### Pré-requisitos

- XAMPP instalado.
- PHP.
- MySQL.
- Navegador atualizado.

### Instalação

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/PayFlow.git
   ```
2. Coloque a pasta do projeto dentro do diretório `htdocs` do XAMPP.
3. Inicie os serviços Apache e MySQL pelo painel do XAMPP.
4. Configure a conexão com o banco de dados conforme as configurações do projeto.
5. Importe o banco de dados, caso o projeto disponibilize um arquivo SQL.
6. Acesse pelo navegador:
   ```
   http://localhost/PayFlow
   ```
